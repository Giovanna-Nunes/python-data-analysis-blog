
# 📊 Python Data Analysis Blog

### Análise de Dados • Python • APIs • Visualização de Dados

Blog acadêmico desenvolvido com **Python e Quarto**, reunindo três atividades práticas que exploram integração com APIs, manipulação de dados, visualização gráfica e conceitos matemáticos aplicados à programação.

O projeto apresenta códigos comentados, explicações das implementações e visualizações dos resultados em um site interativo.

## 🚀 Atividades Desenvolvidas

### 📈 01 — Cotação do Dólar por Período

Consulta à **API PTAX do Banco Central do Brasil** para analisar a variação da cotação do dólar em um período determinado.

**Principais funcionalidades:**
- Consulta de cotações por mês e ano.
- Integração com a API do Banco Central.
- Organização e manipulação dos dados com Pandas.
- Visualização dos resultados em um gráfico de linha.

**Tecnologias:** `Python` `Requests` `Pandas` `Plotly`

📄 [Visualizar atividade](https://giovanna-nunes.github.io/python-data-analysis-blog/posts/cotacao-dolar/)

---

### 🚌 02 — Monitoramento de Frota de Ônibus

Aplicação desenvolvida para consultar e representar informações geográficas de uma linha de ônibus de São Paulo, utilizando a **API Olho Vivo da SPTrans**.

**Linha utilizada:** N140-11 — Terminal Pirituba / Vila Mirante.

**Principais funcionalidades:**
- Consulta de linhas, paradas e posições dos veículos.
- Integração com a API Olho Vivo.
- Representação geográfica dos dados com Folium.
- Visualização de paradas e ônibus por marcadores.
- Exportação do mapa interativo em HTML.

**Tecnologias:** `Python` `Requests` `Folium` `API REST`

📄 [Visualizar atividade](https://giovanna-nunes.github.io/python-data-analysis-blog/posts/frota-onibus/)

> **Nota:** O mapa apresenta posições registradas durante o desenvolvimento da atividade, não representando um monitoramento em tempo real.

---

### 📉 03 — Regressão Linear

Implementação de um modelo de **regressão linear utilizando a formulação matricial**, aplicado a dados simulados sobre a relação entre anos de estudo e salário.

**Principais funcionalidades:**
- Leitura de dados armazenados em arquivos TXT.
- Manipulação de vetores e matrizes com NumPy.
- Cálculo dos coeficientes da regressão linear.
- Visualização dos dados e da reta estimada.

**Tecnologias:** `Python` `NumPy` `Pandas` `Plotnine`

📄 [Visualizar atividade](https://giovanna-nunes.github.io/python-data-analysis-blog/posts/regressao-linear/)
